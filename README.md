# Elâ Güzellik Atölyesi

Vite + React + Tailwind (v4) · JavaScript

    npm install
    npm run dev      # geliştirme
    npm run build    # dist/ üretir

**Vercel:** projeyi GitHub'a at, Vercel'de "Import" de. Framework otomatik "Vite" algılanır, ayar gerekmez.

İçerik (telefon, adres, hizmetler, saatler): `src/data/site.js`
Renkler ve fontlar: `src/index.css` içindeki `@theme`
